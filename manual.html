1. What is ScanBox?

Do you have a large digital library of unidentified pictures? Perhaps you have some contracts which have been photocopied and sent as images that your screen reader cannot read. Or you may have family photographs you would like to preserve, but do not know what they contain.

Enter ScanBox. It can recognise documents, describe photographs and make inaccessible content from other applications available to your screen reader. Import one picture or dozens at a time. Save useful descriptions in the Photo Library, turn an inaccessible PDF into readable text, or send a PDF to Microsoft Word on Windows.

ScanBox works locally. It is useful when online AI is unavailable, if your screen reader does not describe images, or when your documents and photographs should remain on your own computer.

2. Getting Started

ScanBox opens at the Scan tab. Use Ctrl+Tab to move between its three tabs:

  • Scan works with a connected scanner or camera.
  • Import works with files already on your computer.
  • Photo Library contains the photograph descriptions you have saved.

Results appear in the Results area, ready to read, select, copy or save. Press F1 at any time to open this guide.

3. Scan a Document or Photograph

Use the Scan tab when you wish to digitise and have a physical photograph described, OCR a physical document,, or ensure your face is in view in before a meeting,.

  • Scan and Read Document scans a page and reads its text.
  • Scan and Save Images scans without creating a reading result. Choose one page to save as JPEG or multiple pages to save together as one PDF. ScanBox checks text orientation, reports whether each page is upright or otherwise, and alerts you before rotating it. If orientation cannot be determined reliably, the page is saved as scanned.
  • OCR using Camera photographs a page and reads its text.
  • Scan Photo scans and describes a printed photograph.
  • Take Photo captures and describes what your camera sees.
  • FaceAlign announces the position of your face in a front-facing camera.

These commands are the same on Windows and macOS. The Scanner and Camera pages in Settings list the detected devices. Choose a default device to use it throughout ScanBox, or choose Ask me each time to select it during a workflow.

Camera timing

The Camera tab within Settings contains a number of controls useful if you're attempting to line up a perfect shot. Delay before first capture gives you an opportunity to ensure everything is focused correctly before the shot is taken. You can set a delay in seconds if taking multiple pictures. Lastly, enter the value for the number of captures you would like ScanBox to take continuously, with 0 being the value for continuous capture.

Using a phone

A phone mounted above a page can give clearer results than a laptop webcam. Windows 11 can use a supported Android phone as a connected camera. A Mac can use an iPhone through Continuity Camera. Once the phone is available as a camera on the computer, it will automatically appear in ScanBox.

ScanBox may recognise clear handwriting, but it does not specifically detect handwriting and results are less reliable than printed text. There is no separate handwriting mode.

4. Import

  • Import Document reads and optionally converts a document image or PDF.
  • Import PDF from Current Browser Tab downloads and reads a public HTTPS PDF open in Chrome, Edge, Firefox or Safari. Press Control+Shift+hyphen while the browser is active to run the same command.
  • Import Photo describes photographs and adds the descriptions to Scanbox's photo library.

The PDF OCR radio buttons are No OCR., OCR only pages with no selectable text., and OCR each page, including pages that contain selectable text. On Windows, table-aware Word conversion is available only with No OCR.

Windows uses its native OCR engine. macOS uses Apple Vision. No separate OCR package is required.

When Qwen3-VL 2B is installed, Ask About Photo can answer a specific question about the current photograph. Its answer does not replace the description stored in the Photo Library.

5. Use the Photo Library

The Photo Library lets you return to a photograph without describing it again. Select an entry to read its description. You can open the original photo, open its folder, copy its file location, ask Qwen a question about it, or remove the stored description. Removing a description does not delete the photograph.

6. Choose a Local AI Model

Open Settings and choose the AI page to install or select a model:

  • Florence-2 Base is the smaller, quicker Windows option. It is useful for browsing a collection and getting a brief description.
  • Qwen3-VL 2B is larger and usually provides a fuller, more accurate description. It also supports questions about photographs and the active window.

The current macOS preview offers Qwen3-VL 2B only.

Qwen is an optional download of about 2.28 GB. On computers with at least 8 GB of memory, ScanBox can keep it ready in the background for faster later descriptions. Printed document OCR works without either model.

On Windows, ScanBox prefers a recognisable dedicated graphics processor over integrated graphics when Qwen uses Vulkan. Choose Local AI Acceleration from the Help menu to hear the active model and the graphics processor used by the current or most recent description.

Another local AI

If Ollama, LM Studio or vLLM is already running locally, choose Another local AI on this computer, then choose Find Local AI. ScanBox lists every model returned by every detected service. Select the model you want to use for document OCR, image descriptions and image questions. To use a nonstandard connection such as port 8001, enter its private IP address, port, API type and optional API key before finding models.

ScanBox restricts these connections to this computer or a private-network address, and built-in ScanBox AI remains the default. The selected local service controls its own network and privacy behaviour.

7. Describe Another Application

ScanBox can remain in the background while you use Safari, Mail, a web browser or another application. Bring the required window to the foreground, then use:

  • Ctrl+\ to describe the active window.
  • Ctrl+Shift+\ to read its text.
  • Ctrl+Shift+/ to ask Qwen a question about it.

The shortcuts use the Control key on both Windows and macOS. On macOS, allow ScanBox to record the screen when the system first asks. Only the active window is captured.

While a window is being processed, ScanBox places Processing... in Results. You can return to ScanBox and navigate normally; the placeholder is replaced when the result arrives. You can also close ScanBox during processing to cancel the work and exit.

Use Ctrl+Alt+\ on Windows, or Control+Option+\ on macOS, to hide or restore ScanBox.

8. Useful Settings

Open Settings with Ctrl+, on Windows or Command+, on macOS. Settings include:

  • collecting several scanned pages in one result;
  • opening PDF results in Microsoft Word on Windows;
  • camera delays and repeated captures;
  • installing and choosing an AI model;
  • checking for updates; and
  • removing temporary output when ScanBox closes.

9. Help and Troubleshooting

The Help menu contains this guide, Local AI Acceleration, Check for Updates, Donate to Project, license information and About ScanBox. Portable builds can download and install an accepted update while retaining settings and downloaded AI models.

  • If a scanned PDF has no selectable text, choose one of the two OCR modes and import it again. If its existing text is corrupt or incomplete, choose OCR each page, including pages that contain selectable text.
  • If camera text is unclear, keep the page steady, fill the picture with the page and reduce glare.
  • If an AI feature is unavailable, open the AI page in Settings and check that the required model is installed.
  • If macOS screen shortcuts do not work, allow ScanBox under System Settings, Privacy & Security, Screen Recording, then reopen ScanBox.
  • If importing the current browser PDF does not work on macOS, allow ScanBox under System Settings, Privacy & Security, Accessibility, then reopen ScanBox.

10. Privacy

Document recognition, screen analysis and photograph descriptions are performed on your computer. ScanBox does not upload your documents or images. An internet connection is used only to download an AI model, check for updates or open a link you choose from the Help menu.
