ScanBox User Manual

ScanBox is a scanning, document-recognition, and photograph-description application for Windows. It is designed for efficient use with a screen reader. Documents and images are processed locally on your computer; they are not uploaded to an external service under the standard configuration.

1. Getting Started

When ScanBox opens, its main window is maximised to provide sufficient space for reviewing results. Three tabs appear near the top of the window: Document, Photo Description, and Photo Library. Use Ctrl+Tab, or the tab-navigation commands provided by your screen reader, to move between them.

The main results area appears below the tabs and displays recognised text or photograph descriptions. Commands for saving or discarding the current work appear beneath the results area.

Press Ctrl+, (Ctrl and comma) at any time to open Settings.

2. Document OCR

Use this tab to convert a scanned page, an image of a document, or a PDF file into readable, selectable text.

  • Scan Document — scans a page using a connected Windows scanner.
  • Import Document — opens a file-selection dialog for choosing an existing image or PDF file.

When a PDF is imported, ScanBox can present its recognised text directly in the results area. Alternatively, if Microsoft Word is installed, ScanBox can convert the PDF to a DOCX document and open it in Word. Choose the preferred behaviour under Settings > General > PDF reading destination. This option also applies to scanned PDF files whose pages must first be recognised with OCR.

ScanBox first reads the page using its built-in optical character recognition (OCR). A clear, high-confidence result is presented immediately. If confidence is low, or handwriting appears to be present, ScanBox automatically attempts a more detailed reading with the local AI model described in section 5. No separate mode is required for handwritten documents.

Note: Handwriting recognition and enhanced processing of low-confidence document text require the local AI model. Standard document scanning and OCR remain available without it.

3. Photograph Description

Use this tab to produce a written description of a photograph.

  • Scan Photo — scans a photograph using a connected scanner.
  • Import Photo — opens a file-selection dialog for choosing an existing photograph.

The Use OCR for text in photographs checkbox may improve the reading of important visible text, such as wording on a plaque, receipt, or book cover. Leave this option cleared for photographs without significant text so that processing remains focused on the visual content.

Describing a photograph requires the local AI model to be installed (see section 5). If it is not installed yet, ScanBox will offer to install it the first time you try.

4. Photo Library

The Photo Library retains completed descriptions so that a photograph does not need to be processed again. Select an entry to read its full description, or use the commands beneath the list:

  • Open Photo — opens the original image file.
  • Open Containing Folder — opens the folder the photo is stored in.
  • Copy Path — copies the photo's file location to the clipboard.
  • Remove Stored Description — deletes just the saved description, not the photo itself.

5. Setting Up the Local AI Model

Photograph description and enhanced recognition of difficult documents require a local AI model. Installation is optional; standard document scanning remains available without it.

Installing a model

  1. Press Ctrl+, to open Settings.
  2. Go to the AI tab.
  3. Choose Install or update local AI model.
  4. You will be asked to pick a size:
    • Smaller — faster, with lower accuracy, about 357 MB to download.
    • Larger — slower, with improved accuracy, about 1.06 GB to download.
  5. Confirm the selection. The download proceeds in the background, with progress announcements provided through the active screen reader. ScanBox remains available for other work during the download.

Choosing between the two sizes

Both model sizes may be installed at the same time and selected as required:

  1. Press Ctrl+, to open Settings.
  2. Go to the AI tab. At the top, above the install button, is a "Photo/document model" choice with a radio button for each installed size (just one button if only one size is installed, or two if both are).
  3. Select the model to use, then choose OK.

The change takes effect immediately and does not require a restart. It applies to subsequent photograph descriptions and enhanced document recognition until another model is selected. If no model is installed, the page displays an explanatory message instead of a model choice.

Deleting a model

Underneath the model choice is a Delete selected model button. It removes the selected model from the computer and releases the disk space it occupied. Confirmation is required. The Settings dialog closes after the removal; reopen it to make further changes. A removed model may be reinstalled later by selecting Install or update local AI model.

Using an online model (advanced)

ScanBox can pass an image and its instructions to a separate command-line program. This makes it possible to use an online vision service if required. ScanBox does not include an online-service connector, so a small helper program supplied by the service provider or written for its API is required.

Privacy notice: An online helper may upload photographs, document images, screenshots, recognised text, and instructions to an external service. Review the provider's privacy, retention, security, and cost policies before proceeding. Do not place an API key directly in the ScanBox command. Store it securely, such as in an environment variable or the credential system recommended by the provider.

For example, suppose a helper program named online_vision.py has been placed in C:\ScanBox Tools. Its ScanBox command might be:

python "C:\ScanBox Tools\online_vision.py" --task "{task}" --image "{image}" --prompt "{prompt}" --draft "{draft}"

The helper program in this example is illustrative and is not included with ScanBox. It would receive the following values:

  • {task} — either describe for a photograph or transcribe for a document.
  • {image} — the full path of the image to process.
  • {prompt} — ScanBox's instructions for the requested task.
  • {draft} — the path of an optional OCR draft. This value may be empty.

The helper must send the completed description or transcription to its standard output as plain text. It should report failures through its error output and return a non-zero exit status.

  1. Install and test the helper according to the provider's instructions.
  2. If a built-in local AI model is installed, remove it under Settings > AI. Installed local models take precedence over a custom command.
  3. Open Settings > AI and choose Set custom AI command.
  4. Enter the command, including the required placeholders, and select OK.
  5. Test the configuration with a non-sensitive image before processing private material.

6. Settings

Settings (Ctrl+,) has two tabs:

General

  • Delete output files upon exit — automatically removes files created in the output folder when ScanBox closes.
  • Check for updates on startup — checks the official ScanBox release page when the application starts. This option is enabled by default. The startup check remains silent unless a newer version is available.
  • Keep ScanBox in the notification area when minimized — allows ScanBox to remain available in the background after its main window is minimized. This option is enabled by default. Closing the main window still exits ScanBox.
  • PDF reading destination — choose whether PDF results appear inside ScanBox, or are converted into a Word document and opened in Microsoft Word (only available if Word is installed on your computer).
  • Append text to buffer for each Scan or Import — turn this on if you are working through a multi-page document and want every page's text collected together instead of replacing the previous page.
  • Show document page headings in results — adds a heading before each page's text when working through multiple pages.
  • Enable diagnostic logging — keeps a log file of ScanBox activity that may assist with diagnosing a problem.

AI

Use this page to select an installed local AI model, remove a model, install or update the local AI components, or configure a custom local AI command. See section 5 for further information.

Help menu

The Help menu provides access to this user manual, a manual update check, and the About dialog. Press F1 to open the manual at any time. The About dialog displays the installed ScanBox version.

7. Saving Your Results

  • Save Text — appears once there is text to save, and saves it as a plain-text file.
  • Save Images — appears after a scan, letting you keep copies of the scanned images themselves.
  • Discard Session — clears the current results and begins a new session.

You can also select any text in the results area at any time and copy it with the usual copy command (Ctrl+C).

8. Reading PDF Files

Import a PDF from the Document tab. What happens next depends on the PDF destination setting described above:

  • Show PDF reading in ScanBox — the text appears directly in the results area. Selectable text already in the PDF is used as-is; scanned pages are read with OCR or the local AI model as needed.
  • Create a DOCX and open it in Microsoft Word — ScanBox converts the PDF into a Word document and opens it for you. This option only appears if Microsoft Word is installed.

9. Screen Reader Support

ScanBox announces status information and results through a supported screen reader, including NVDA, JAWS, System Access, and Windows Narrator/SAPI. No additional configuration is required. When no supported screen reader is active, ScanBox operates visually without speech output.

Buttons, checkboxes, lists, and other interactive elements use standard accessible Windows controls. The main window opens maximised by default to provide ample space for reviewing results.

Describing or reading the active window

  • Press Ctrl+\ to describe the meaningful visual content of the active window.
  • Press Ctrl+Shift+\ to recognise text displayed in the active window.
  • Press Ctrl+Alt+\ to toggle the ScanBox window. When ScanBox is the active window, the shortcut minimizes it to the notification area. When ScanBox is hidden, minimized, or behind another application, the shortcut restores it and returns keyboard focus to it.

Keep the required application in the foreground when using either shortcut. ScanBox analyses the pixels currently visible within that window; content hidden behind another window or outside the visible area cannot be included.

10. Tips and Troubleshooting

  • ScanBox remembers the last folder you imported from, so you do not need to navigate back to it every time.
  • Photograph descriptions may take additional time during the first use after installing or changing a model, because the model must be loaded into memory. Subsequent descriptions are generally faster.
  • If a photograph description appears inaccurate, enable Use OCR for text in photographs when the image contains important text, or select the larger model under Settings > AI for improved accuracy.
  • If the local AI features are unavailable, check Settings > AI to make sure a model has been installed.

11. Privacy

Document scanning, text recognition, screen analysis, and photograph description are performed locally on your computer. Documents, screenshots, and photographs are not uploaded under the standard configuration.

An internet connection is used when downloading local AI model files and when checking GitHub for a newer ScanBox release. The startup update check may be disabled under Settings > General. Advanced users may configure a different AI command, including one that communicates with an external service; such a configuration is not enabled by default.
